# 需求分析文档 —— 基于 AI 智能的电商商品销售分析与预测系统

## 1. 引言

### 1.1 编写目的

本文档旨在明确系统的功能需求、非功能需求、用户角色以及典型使用场景，为后续设计、开发和测试提供依据。

### 1.2 项目背景

电商企业积累了大量销售数据，但缺乏有效的分析工具和预测能力。本系统通过数据可视化和机器学习技术，帮助运营人员快速了解销售状况、预测未来销量并管理库存。

### 1.3 目标用户

- 电商运营人员
- 数据分析师
- 库存管理人员

## 2. 用户角色与权限

| 角色 | 权限描述 |
|------|----------|
| 管理员 | 上传数据、查看所有分析报表、执行预测、管理预警 |
| 访客（演示模式） | 仅可查看预置数据和分析结果，不可上传 |

## 3. 功能需求

### 3.1 数据管理模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-01 | 系统应支持上传 CSV 格式的销售数据文件 | 高 |
| F-02 | 系统应验证文件格式和必要字段（Order_Date, Product_Category, Quantity, Total_Sales, Profit 等） | 高 |
| F-03 | 系统应自动清洗数据：处理缺失值、转换日期类型、按日期排序 | 高 |
| F-04 | 系统应展示数据预览（前20行）和字段统计信息（行数、日期范围、缺失率） | 中 |

### 3.2 销售分析模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-05 | 系统应提供销售额/销量的时间趋势图（可按日、月聚合） | 高 |
| F-06 | 系统应展示热销产品排行（按销量或销售额，可限定产品类别） | 高 |
| F-07 | 系统应展示不同地区的销售额占比（饼图或柱状图） | 高 |
| F-08 | 系统应展示客户细分（Consumer/Corporate/Home Office）的销售额占比 | 高 |
| F-09 | 系统应展示折扣效果分析：不同折扣区间（0%, 1-10%, 11-20%, 21%+）的平均销量 | 高 |
| F-10 | 系统应展示利润最高的产品类别或产品 | 中 |

### 3.3 销量预测模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-11 | 用户可选择产品类别（Technology, Furniture, Office Supplies, Clothing & Accessories） | 高 |
| F-12 | 用户可选择预测天数（7、14 或 30 天） | 高 |
| F-13 | 系统应基于历史销量数据，使用机器学习模型（LightGBM）返回未来指定天数的每日预测销量 | 高 |
| F-14 | 系统应同时提供基线模型（移动平均或Prophet）的预测结果作为对比 | 中 |
| F-15 | 系统应展示预测曲线（历史30天 + 未来预测值） | 高 |

### 3.4 库存预警模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-16 | 系统应模拟每个产品类别的当前库存（基于过去30天日均销量 × 安全天数） | 高 |
| F-17 | 系统应结合未来7天预测销量，计算安全库存（预测销量 × 1.2） | 高 |
| F-18 | 若当前库存 < 安全库存，系统应触发预警，并显示建议补货量 | 高 |
| F-19 | 预警结果应以表格形式展示，并支持刷新 | 中 |

### 3.5 可视化报表模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-20 | 系统应提供一个仪表板页面，整合核心分析图表（趋势、排行、分布等） | 高 |
| F-21 | 图表应支持交互（如悬停显示数值、图例筛选） | 中 |
| F-22 | 支持导出图表为图片（可选） | 低 |

### 3.6 系统管理模块

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| F-23 | 系统应提供简单的登录页（用户名/密码可硬编码） | 高 |
| F-24 | 用户登录后可访问所有功能页面 | 高 |

## 4. 非功能需求

| 编号 | 需求描述 | 目标值 |
|------|----------|--------|
| NF-01 | 响应时间：预测接口应在 3 秒内返回结果 | ≤ 3s |
| NF-02 | 并发支持：支持至少 5 个用户同时访问 | 5 并发 |
| NF-03 | 数据安全：上传的数据仅存储在本地数据库，不对外泄露 | 本地存储 |
| NF-04 | 可维护性：代码结构清晰，关键模块有注释 | 通过 |
| NF-05 | 可用性：用户无需培训即可完成主要操作流程 | 任务成功率 ≥ 90% |

## 5. 用例图说明

系统的主要参与者为“运营人员”。用例包括：
- 上传数据
- 查看销售分析（趋势、排行、分布）
- 执行销量预测
- 查看库存预警
- 登录系统

## 6. 业务规则

1. 库存模拟规则：当前库存 = 过去30天该品类日均销量 × 14  
2. 安全库存系数：1.2（即预留20%缓冲）  
3. 预测模型每周自动重训练（在系统使用过程中可手动触发）  
4. 折扣区间划分：0%、1-10%、11-20%、21%+  

## 7. 数据字典（关键字段）

| 字段 | 类型 | 取值范围 | 说明 |
|------|------|----------|------|
| Order_Date | DATE | 2023-01-02 ~ 2025-12-31 | 订单日期 |
| Product_Category | VARCHAR | Technology, Furniture, Office Supplies, Clothing & Accessories | 产品大类 |
| Quantity | INT | ≥1 | 销售数量 |
| Total_Sales | DECIMAL | ≥0 | 订单总销售额 |
| Profit | DECIMAL | 可负 | 订单利润 |
| Discount_Percent | INT | 0~30 | 折扣百分比 |
| Customer_Segment | VARCHAR | Consumer, Corporate, Home Office | 客户类型 |
| Region | VARCHAR | Asia Pacific, Europe, Middle East & Africa, North America, South America | 全球区域 |
