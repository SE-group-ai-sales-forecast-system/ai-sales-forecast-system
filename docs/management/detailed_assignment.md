## 核心原则

1. **砍需求**：只保留 **数据上传 → 销售分析（趋势图+热销榜） → 销量预测 → 库存预警** 这条主线。客户细分、折扣分析、报表导出等全部放到“扩展功能”文档中，不实现代码。
2. **技术栈降维**：前端统一用 **Streamlit**，不再手写HTML/JS。后端用 **FastAPI** 提供预测接口即可，分析功能直接用Streamlit读取数据库。
3. **模型简单**：就用 **移动平均** 做预测（3号实现），LightGBM作为备选，如果时间不够就放弃。预测精度不重要，能出曲线就行。
4. **数据固定**：直接使用预处理好的 `daily_sales.csv` 文件，先不做动态上传（演示时手动替换文件即可）。这样省去上传和解析逻辑。
5. **每日站会**：每晚10点线上同步进度，15分钟，每个人说“今天完成什么、明天做什么、有什么阻塞”。
